# 슬라이드 1

안녕하세요. 1-14. AC, DC, BLDC, 스테핑 모터와 서보 제어 내용을 시작하겠습니다. 모터는 전기 에너지를 회전 운동으로 변환하는 장치입니다. 하지만 모터의 종류에 따라 속도와 토크를 제어하는 방법이 서로 다릅니다. AC 모터는 주파수와 전압을 조절하고, DC 모터는 주로 전압이나 PWM을 이용합니다. BLDC 모터는 전자적인 정류가 필요하며, 스테핑 모터는 펄스의 개수와 주파수로 위치와 속도를 제어합니다.

# 슬라이드 3

V/F 제어는 전압(Voltage)과 주파수(Frequency)의 비율을 일정하게 유지하는 방식이며, 실시간 제어 기능은 없습니다. 범용 인버터에서 가장 널리 사용하는 기본적인 제어 방식입니다. 인버터 내부에서는 일반적으로 다음과 같은 전력 변환이 이루어집니다. AC 입력 → DC 정류 → PWM 스위칭 → 가변 주파수 AC 출력 주파수를 낮추면 모터 속도가 감소하고, 주파수를 높이면 모터 속도가 증가합니다. 하지만 주파수만 변경하면 모터 내부 자속이 달라질 수 있으므로 전압도 함께 변경합니다.

# 슬라이드 5

FOC(Field-Oriented Control)는 모터 전류를 자속 성분과 토크 성분으로 분리하여 제어하는 방식이며, Feedback 을 기반으로 실시간 제어를 포함합니다. 우리말로는 자속 기준 제어 또는 벡터 제어라고 표현합니다. FOC는 3상 전류를 수학적으로 변환하여 모터의 자속과 토크를 독립적으로 제어합니다. 기본적인 변환 과정은 다음과 같습니다. 3상 전류(a, b, c) → Clarke 변환 → αβ 좌표계 → Park 변환 → dq 좌표계 - d축 전류: 모터의 자속을 제어합니다.

# 슬라이드 8

DC 모터는 공급 전압에 따라 속도가 비교적 직관적으로 변합니다. 일반적으로 다음과 같이 이해할 수 있습니다. - 전압 증가 → 회전속도 증가 - 전압 감소 → 회전속도 감소 - 극성 변경 → 회전 방향 변경 DC 모터의 기본 전압 관계는 다음과 같습니다. - $V$: 공급 전압 - $E$: 역기전력 - $I$: 전류 - $R$: 전기자 저항 모터가 회전하면 역기전력($E$)이 발생합니다. 모터가 정지해 있을 때는 역기전력이 거의 없으므로 큰 기동 전류가 흐를 수 있습니다.

# 슬라이드 10

DC 모터의 속도는 PWM(Pulse Width Modulation)을 이용하여 제어할 수 있습니다. PWM은 전원을 매우 빠르게 ON/OFF하면서 ON 상태의 비율을 조절하는 방식입니다. 이 비율을 듀티비(Duty Ratio)라고 합니다. 예를 들어 12V 전원에서 듀티비를 50%로 설정하면 모터는 평균적으로 약 6V에 해당하는 에너지를 공급받습니다. - Duty 100% → 최대 출력 - Duty 50% → 약 절반의 평균 출력 - Duty 0% → 출력 없음 실제로는 전압 자체를 낮추는 것이 아니라 매우 빠르게 ON/OFF하여 평균 전력을 조절합니다.

# 슬라이드 18

서보(Servo)는 특정한 모터 종류를 의미하기보다, 명령한 위치와 속도, 토크를 정확하게 따라가도록 구성한 폐루프 제어 시스템을 의미합니다. 서보 시스템은 일반적으로 다음 요소로 구성됩니다. - 모터 - 엔코더 또는 리졸버 - 서보 드라이브 - 상위 제어기 서보 모터는 반드시 피드백 장치를 사용하여 실제 위치와 속도를 측정합니다. 서보 드라이브는 목표값과 실제값을 비교하여 오차를 계산하고, 오차가 줄어들도록 출력을 계속 보정합니다. 서보 시스템에는 다양한 모터를 사용할 수 있습니다.
