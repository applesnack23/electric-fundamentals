# 1-14. AC, DC, BLDC, 스테핑 모터와 서보 제어

모터는 전기 에너지를 회전 운동으로 변환하는 장치입니다.

하지만 모터의 종류에 따라 속도와 토크를 제어하는 방법이 서로 다릅니다.

AC 모터는 주파수와 전압을 조절하고, DC 모터는 주로 전압이나 PWM을 이용합니다. BLDC 모터는 전자적인 정류가 필요하며, 스테핑 모터는 펄스의 개수와 주파수로 위치와 속도를 제어합니다.

서보 시스템은 이러한 모터에 엔코더와 드라이브를 추가하여 위치, 속도, 토크를 정밀하게 제어합니다.


---

#### AC 모터 제어 방식

AC 모터의 회전속도는 전원의 주파수와 모터의 극수에 따라 결정됩니다.

동기속도는 다음과 같이 계산합니다.

$$
N_s=120f/P
$$

- $N_s$: 동기속도(rpm)
- $f$: 전원 주파수(Hz)
- $P$: 모터 극수

예를 들어 4극 모터에 60Hz 전원을 공급하면 동기속도는 다음과 같습니다.

$$
N_s = \frac{120 \times 60}{4} = 1800rpm
$$

유도 모터는 실제 운전 시 슬립(Slip)이 발생하므로 실제 회전속도는 동기속도보다 약간 낮습니다.

AC 모터의 속도를 조절하려면 인버터를 이용하여 출력 주파수를 변경해야 합니다.


---

#### V/F

![V/F](../assets/motor-types-and-servo-control-01.png)

V/F 제어는 전압(Voltage)과 주파수(Frequency)의 비율을 일정하게 유지하는 방식이며, 실시간 제어 기능은 없습니다.

범용 인버터에서 가장 널리 사용하는 기본적인 제어 방식입니다.

인버터 내부에서는 일반적으로 다음과 같은 전력 변환이 이루어집니다.

AC 입력 → DC 정류 → PWM 스위칭 → 가변 주파수 AC 출력

주파수를 낮추면 모터 속도가 감소하고, 주파수를 높이면 모터 속도가 증가합니다.

하지만 주파수만 변경하면 모터 내부 자속이 달라질 수 있으므로 전압도 함께 변경합니다.

예를 들어 정격이 380V, 60Hz인 모터의 V/F 비율은 다음과 같습니다.

$$

\frac{380V}{60Hz} \approx 6.33V/Hz

$$

30Hz로 운전한다면 약 190V를 공급하여 비율을 유지합니다.

장점

- 구조와 제어 원리가 단순합니다.
- 비용이 비교적 저렴합니다.
- 설정이 쉽습니다.
- 팬, 펌프, 단순 컨베이어에 적합합니다.

단점

- 저속에서 토크가 감소할 수 있습니다.
- 부하 변화에 따라 속도가 달라질 수 있습니다.
- 정밀한 토크 제어가 어렵습니다.
- 위치 제어에는 적합하지 않습니다.

V/F 제어가 토크를 전혀 제어하지 못하는 것은 아닙니다. 다만 토크를 직접적이고 정밀하게 제어하는 방식은 아닙니다.

---

#### FOC (=Field Oriented Control)

![FOC (=Field Oriented Control)](../assets/motor-types-and-servo-control-02.png)

FOC(Field-Oriented Control)는 모터 전류를 자속 성분과 토크 성분으로 분리하여 제어하는 방식이며, Feedback 을 기반으로 실시간 제어를 포함합니다.

우리말로는 자속 기준 제어 또는 벡터 제어라고 표현합니다.

FOC는 3상 전류를 수학적으로 변환하여 모터의 자속과 토크를 독립적으로 제어합니다.

기본적인 변환 과정은 다음과 같습니다.

3상 전류(a, b, c) → Clarke 변환 → αβ 좌표계 → Park 변환 → dq 좌표계

- d축 전류: 모터의 자속을 제어합니다.
- q축 전류: 모터의 토크를 제어합니다.

FOC는 모터 회전자의 위치나 각도를 알아야 하므로 다음과 같은 센서를 사용할 수 있습니다.

- 엔코더
- 리졸버
- 홀 센서

다만 센서를 사용하지 않고 전압과 전류로 위치를 추정하는 센서리스 FOC 방식도 있습니다.

장점

- 저속에서도 높은 토크를 낼 수 있습니다.
- 토크 응답이 빠릅니다.
- 속도와 위치를 정밀하게 제어할 수 있습니다.
- 모터 효율과 응답성이 우수합니다.

단점

- 제어 알고리즘이 복잡합니다.
- 모터 파라미터가 필요합니다.
- 전류 센서와 위치 센서가 필요할 수 있습니다.
- 제어기의 연산 성능이 중요합니다.

FOC는 고성능 인버터, BLDC 모터, PMSM, 전기자동차, 로봇, 서보 시스템에서 널리 사용합니다.


---

#### V/F 제어와 FOC 비교

| 구분 | V/F 제어 | FOC 제어 |
| --- | --- | --- |
| 제어 기준 | 전압과 주파수의 비율 | 자속과 토크 성분 |
| 피드백 | 일반적으로 없음 | 센서 또는 추정값 사용 |
| 저속 토크 | 낮을 수 있음 | 매우 우수 |
| 속도 정밀도 | 보통 | 매우 우수 |
| 토크 제어 | 제한적 | 정밀하게 가능 |
| 제어 난이도 | 낮음 | 높음 |
| 주요 용도 | 팬, 펌프, 단순 컨베이어 | 서보, 로봇, 전기차 |

#### DC 모터 제어 방식

![DC 모터 제어 방식](../assets/motor-types-and-servo-control-03.png)

DC 모터는 공급 전압에 따라 속도가 비교적 직관적으로 변합니다.

일반적으로 다음과 같이 이해할 수 있습니다.

- 전압 증가 → 회전속도 증가
- 전압 감소 → 회전속도 감소
- 극성 변경 → 회전 방향 변경

DC 모터의 기본 전압 관계는 다음과 같습니다.

$$

V = E + IR

$$

- $V$: 공급 전압
- $E$: 역기전력
- $I$: 전류
- $R$: 전기자 저항

모터가 회전하면 역기전력($E$)이 발생합니다.

모터가 정지해 있을 때는 역기전력이 거의 없으므로 큰 기동 전류가 흐를 수 있습니다.


---

#### PWM (=Pulse Width Modulation)

![PWM (=Pulse Width Modulation)](../assets/motor-types-and-servo-control-04.png)

DC 모터의 속도는 PWM(Pulse Width Modulation)을 이용하여 제어할 수 있습니다.

PWM은 전원을 매우 빠르게 ON/OFF하면서 ON 상태의 비율을 조절하는 방식입니다.

이 비율을 듀티비(Duty Ratio)라고 합니다.

예를 들어 12V 전원에서 듀티비를 50%로 설정하면 모터는 평균적으로 약 6V에 해당하는 에너지를 공급받습니다.

- Duty 100% → 최대 출력
- Duty 50% → 약 절반의 평균 출력
- Duty 0% → 출력 없음

실제로는 전압 자체를 낮추는 것이 아니라 매우 빠르게 ON/OFF하여 평균 전력을 조절합니다.

PWM을 이용한 실제 전압 생성과 모터 드라이브 회로는 마이크로컨트롤러 과정에서 자세히 다룹니다.


---

#### BLDC 모터

BLDC(Brushless DC) 모터는 브러시가 없는 DC 모터입니다.

![BLDC 모터](../assets/motor-types-and-servo-control-05.png)

일반 DC 모터는 브러시와 정류자를 이용하여 코일에 흐르는 전류 방향을 기계적으로 변경합니다.

BLDC 모터는 브러시 대신 전력 반도체를 이용하여 전류 방향을 전자적으로 전환합니다.

이를 전자 정류(Electronic Commutation)라고 합니다.

BLDC 모터는 일반적으로 다음 요소가 필요합니다.

- BLDC 모터
- 모터 드라이버
- 홀 센서 또는 엔코더
- 마이크로컨트롤러 또는 제어기

BLDC 모터는 6-Step 제어, 사인파 제어, FOC 등의 방식으로 구동할 수 있습니다.


---

#### DC 모터와 BLDC 모터 비교

| 구분 | DC 모터 | BLDC 모터 |
| --- | --- | --- |
| 정류 방식 | 브러시와 정류자 | 전자식 스위칭 |
| 수명 | 브러시 마모로 제한 | 비교적 김 |
| 유지보수 | 브러시 교체 필요 | 적음 |
| 소음 | 비교적 큼 | 작음 |
| 효율 | 보통 | 높음 |
| 속도 제어 | 쉬움 | 드라이버 필요 |
| 제어 난이도 | 낮음 | 높음 |
| 가격 | 비교적 저렴 | 상대적으로 높음 |

BLDC 모터의 수명이 완전히 영구적인 것은 아닙니다. 브러시 마모는 없지만 베어링, 절연, 자석, 전자 부품의 수명은 존재합니다.


---

#### 스테핑 모터

![스테핑 모터](../assets/motor-types-and-servo-control-06.png)

스테핑 모터는 입력 펄스에 따라 일정한 각도씩 회전하는 모터입니다.

펄스 한 개가 입력될 때마다 정해진 스텝 각도만큼 이동합니다.

예를 들어 스텝 각도가 1.8°인 모터는 200개의 펄스를 입력하면 한 바퀴 회전합니다.

$$

360^\circ \div 1.8^\circ = 200

$$

스테핑 모터에서는 다음과 같이 제어합니다.

- 펄스 개수 → 이동 위치
- 펄스 주파수 → 회전속도
- 방향 신호 → 회전 방향

따라서 별도의 엔코더가 없어도 위치를 제어할 수 있습니다.

하지만 과부하가 발생하면 명령 펄스와 실제 위치가 달라지는 탈조(Step Loss)가 발생할 수 있습니다.


---

#### 모터 비교

| 구분 | AC 모터 | DC 모터 | BLDC 모터 | 스테핑 모터 |
| --- | --- | --- | --- | --- |
| 주요 장점 | 높은 내구성, 저렴한 가격, 장시간 운전 | 간단한 속도 제어, 높은 기동 토크 | 긴 수명, 고효율, 저소음, 고속 운전 | 펄스로 위치 제어 가능, 저속 토크 우수 |
| 주요 단점 | 속도 제어 시 인버터 필요, 위치 제어 어려움 | 브러시 마모, 유지보수 필요 | 드라이버 필수, 제어 복잡 | 고속 토크 감소, 발열, 진동, 탈조 가능 |
| 속도 제어 | 인버터 필요 | 전압 또는 PWM | 전용 드라이버 필요 | 펄스 주파수 |
| 위치 제어 | 일반적으로 어려움 | 엔코더 필요 | 엔코더 또는 센서 필요 | 펄스 개수 |
| 주요 사용처 | 펌프, 팬, 컨베이어, 공조 설비 | 소형 로봇, 자동차 보조장치, 소형 펌프 | 전기차, AGV, 드론, 로봇 | 3D 프린터, CNC, 프린터 |

#### 서보 시스템

서보(Servo)는 특정한 모터 종류를 의미하기보다, 명령한 위치와 속도, 토크를 정확하게 따라가도록 구성한 폐루프 제어 시스템을 의미합니다.

서보 시스템은 일반적으로 다음 요소로 구성됩니다.

- 모터
- 엔코더 또는 리졸버
- 서보 드라이브
- 상위 제어기

서보 모터는 반드시 피드백 장치를 사용하여 실제 위치와 속도를 측정합니다.

서보 드라이브는 목표값과 실제값을 비교하여 오차를 계산하고, 오차가 줄어들도록 출력을 계속 보정합니다.

서보 시스템에는 다양한 모터를 사용할 수 있습니다.

- DC 모터
- AC 동기 모터
- PMSM
- BLDC 모터
- 스테핑 모터 기반 폐루프 시스템

현대 산업용 서보에서는 영구자석 동기 모터(PMSM) 계열을 가장 많이 사용합니다.

AC 유도 모터도 폐루프 벡터 제어를 이용하여 서보처럼 사용할 수 있지만, 정밀 위치 제어용 산업 서보에서는 PMSM이 일반적입니다.


---

#### 폐루프 제어기

![폐루프 제어기](../assets/motor-types-and-servo-control-07.png)

서보 시스템의 목표는 명령값과 실제값의 오차를 줄이는 것입니다.

$$

e(t) = Setpoint - ProcessValue

$$

- Setpoint: 목표값
- Process Value: 실제 측정값
- Error: 목표값과 실제값의 차이

제어기는 현재 오차를 계산하고 다음 제어 주기에 적용할 출력을 결정합니다.

이 과정을 매우 빠르게 반복하면서 목표 위치나 속도를 유지합니다.

응답 주기가 짧을수록 변화에 빠르게 대응할 수 있지만, 제어기와 센서의 성능도 함께 높아야 합니다.


---

#### PID 제어기

PID 제어기는 비례(P), 적분(I), 미분(D) 세 가지 제어를 결합한 방식입니다.

$$

MV(t)=K_p e(t)+K_i\int_0^t e(\tau)d\tau+K_d\frac{de(t)}{dt}

$$

- $MV(t)$: 제어 출력
- $e(t)$: 오차
- $K_p$: 비례 게인
- $K_i$: 적분 게인
- $K_d$: 미분 게인


---

#### P 제어

![P 제어](../assets/motor-types-and-servo-control-08.png)

$$

MV(t)=K_p e(t)

$$

P 제어는 현재 오차의 크기에 비례하여 출력을 만듭니다.

오차가 크면 출력도 크게 증가하고, 오차가 작으면 출력도 작아집니다.

**특징**

- 응답이 빠릅니다.
- 구조가 단순합니다.
- 정상상태 오차가 남을 수 있습니다.
- 게인이 지나치게 크면 진동이 발생할 수 있습니다.


---

#### I 제어

![I 제어](../assets/motor-types-and-servo-control-09.png)

$$

MV(t)=K_i\int_0^t e(\tau)d\tau

$$

I 제어는 과거의 오차를 누적하여 출력에 반영합니다.

작은 오차가 오랫동안 지속되더라도 적분값이 증가하여 최종적으로 오차를 줄입니다.

**특징**

- 정상상태 오차를 제거하는 데 유리합니다.
- 응답이 느려질 수 있습니다.
- 적분값이 과도하게 누적되는 Integral Windup이 발생할 수 있습니다.


---

#### D 제어

$$

MV(t)=K_d\frac{de(t)}{dt}

$$

D 제어는 오차의 변화 속도를 이용합니다.

오차가 빠르게 변하면 큰 출력을 만들어 변화에 미리 대응합니다.

**특징**

- 급격한 변화에 빠르게 대응합니다.
- 오버슈트와 진동을 줄이는 데 도움을 줍니다.
- 센서 노이즈에 민감합니다.

D 제어는 현재 오차 자체를 증폭하는 것이 아니라, 오차의 변화율에 반응합니다.


---

#### PID 제어 예제

```cpp
double integral = 0, derivative = 0;
double PID_Control(double setpoint, double process_value)
{
    // 1. 오차 계산
    error = setpoint - process_value;	      // 작은 에러에 대한 대응 불가능

    // 2. 적분항 계산
    integral += error * Ts;				          // 누적된 에러에 대해 보상 가능

    // 3. 미분항 계산
    derivative = (error - prev_error) / Ts;	// 외란에 빠르게 대응 가능

    // 4. PID 합산
    MV = (Kp * error) + (Ki * integral) + (Kd * derivative);

    // 5. 현재 오차 저장
    prev_error = error;
    return MV;
}
```

코드의 동작 순서는 다음과 같습니다.

1. 목표값과 실제값의 차이인 오차를 계산합니다.
2. 오차를 시간에 따라 누적하여 적분값을 계산합니다.
3. 이전 오차와 현재 오차의 차이로 미분값을 계산합니다.
4. P, I, D 값을 합산하여 제어 출력을 만듭니다.
5. 현재 오차를 저장하여 다음 제어 주기에 사용합니다.
